# P6 — Laravel-канал (рецепт+пример) + multi-tenant patch API для Flex*

## Phase Context

Фаза закрывает две вещи master §4.8/§4.9 + D15: (1) **Laravel-канал** — рецепт потребления
ThemeOn в Laravel+Vite (докстраница + тестируемый пример); (2) **multi-tenant white-label** —
`serializeThemePatch(patch)→css` в `@themeon/core` с per-type value-грамматикой, экспортируемая

интеграционный пример флоу инъекции в `<head>`.

**Несущий контекст безопасности (H3 final-audit 2026-07-12, ПОДТВЕРЖДЁННАЯ дизайн-дыра класса
stored-XSS):** `serializeThemePatch` инжектит серверный CSS в `<head>` до paint из
tenant-контролируемых значений. Значение цвета тенанта `red}</style><script>…</script>`

значений + reject метасимволов (не escape) fail-loud; **(И2)** fail-closed семантика APCA-гейта
(«провал БЛОКИРУЕТ публикацию», явно). Оба верифицированы RAG — `20_research/R-16_P6-*.md`
(OWASP A05:2025/WSTG 4.11.5). В ядре сейчас ноль валидации значений (`BAD_VALUE` объявлен
`errors.ts`, не используется) — фаза его вводит.

### P6.1 — `serializeThemePatch` + per-type value-грамматика (H3 И1)

**Status:** 🟢 Done
**Intent:** Ввести в `@themeon/core` публичный `serializeThemePatch(patch, opts) → string` —
tenant sys-слой JSON-патч → инъектируемый CSS-блок (`:root{…}` или scoped-селектор) — c ВАЛИДАЦИЕЙ
каждого значения по строгой per-TokenType allowlist-грамматике и reject CSS/HTML-метасимволов
fail-loud. Это фикс H3 И1 (`RAG:✅ 2026-07-15 R-16 §2, OWASP A05:2025/WSTG 4.11.5`). Примитив —
`applyThemePatch(base, patch, opts) → { vars, css }` (валидирует + отдаёт и словарь, и CSS);
`serializeThemePatch` = `.css`-обёртка (имя-контракт D15).

(`BAD_VALUE` объявлен `errors.ts:5`, не используется). Это несущий инвариант всего multi-tenant
