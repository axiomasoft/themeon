### P0.2 — WCAG 2.2 normative contrast policy

**Intent:** Add an explicit WCAG 2.2 contrast engine/result beside APCA and propagate normative vs
advisory semantics through colors and CLI without collapsing the result to one boolean.

**Why:** `RAG:—` `packages/colors/src/contrast.ts` and the package description center APCA; the
audit identifies this as insufficient for normative accessibility. D3 freezes the intended policy,
while exact thresholds and applicability must be verified from official WCAG sources.

**Scope Included:** Text and non-text WCAG policies with documented context inputs; structured
result carrying ratio, threshold, pass and unsupported/indeterminate reason; APCA marked
experimental/advisory; CLI diagnostics and exit semantics distinguishing normative failure,
advisory finding and unsupported context; tests for boundaries, alpha/gradient/invalid inputs and
formatting; public API/API-snapshot updates.

**Scope Excluded:** Claiming legal compliance; WCAG 3 implementation; visual regression testing;
automatic background compositing without declared context; unrelated palette-generation changes.

**Implementation Rules:** No global “accessible=true” without a named policy/context. Exact
threshold equality is tested. Unknown background, gradient and unresolved alpha yield a typed
indeterminate result rather than pass. APCA cannot set a non-zero compliance exit by itself unless
the caller explicitly opts into an advisory gate. Existing APCA consumers receive a documented
compatibility path; public unions/codes are snapshot-tested.

**Code Guidance:** Implement pure calculation separately from policy evaluation and CLI rendering.
Use table-driven boundary fixtures immediately below/above each threshold. Keep result types
discriminated so callers must handle pass/fail/indeterminate. Do not hide unsupported inputs behind
`NaN` or catch-all success.

**Validation:** `pnpm --filter @themeon/colors test`; `pnpm --filter @themeon/cli test`;
`pnpm --filter @themeon/colors typecheck`; `pnpm --filter @themeon/cli typecheck`; public API
snapshots show deliberate additions only; focused CLI fixtures prove exit behavior for normative
failure, APCA advisory and indeterminate input.

**Deliverables:** WCAG policy/result API; retained APCA advisory output; CLI classification and
stable codes; threshold/unknown-context tests; updated package documentation.
