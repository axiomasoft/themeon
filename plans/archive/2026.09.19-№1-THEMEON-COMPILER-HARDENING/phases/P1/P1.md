# P1 — Canonical IR, compiler pipeline and diagnostics

## Phase Context

P1 introduces the compiler architecture promised by D1 after P0 freezes standards/security
behavior. The goal is not a directory rename: authoring input, canonical IR, graph/resolution,
transforms/formats and runtime output become independently testable contracts while current public
behavior stays compatible.

`RAG:—` current semantics are spread across `define.ts`, `types.ts`, `resolve.ts`, `serialize.ts`,
`apply.ts`, DTCG converters and CLI/Vite call sites. The design pass must first characterize those
call graphs and decide migration seams; it may not assume the audit's sample tree is exact.

> **Контракт фазы (contract-first).** Потребляет: terminal P0 contracts and compatibility tests.
> Производит: canonical immutable IR, reference graph, staged compiler, structured diagnostics,
> deterministic fingerprint, instance-scoped extension API and additive public subpaths. Границы:
> no new npm package, no root-export removal, no DOM in IR, no build-time network access.

> **Phase Assurance | v1.**
> Impact: public-contract
> Integration Seams: core-compiler · diagnostic-consumers · runtime-adapters
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: Detailed items must pair each new contract with compatibility and parity tests; any
> public narrowing or runtime dependency requires a new decision rather than implicit refactor.

## Scope Included

IR types for token identity/path/value/references/metadata/source; reference graph and cycle/topology
semantics; normalize/validate/resolve/transform/validate-output/emit pipeline; immutable compiler
context; structured diagnostic model/codes/formatters; deterministic build fingerprint and plugin
cache contribution; instance-scoped parsers/normalizers/validators/transforms/formats with declared
capabilities; additive `./authoring`, `./compiler`, `./runtime`, `./dtcg`, `./tenant` subpaths;
architecture/ADR documents and migration adapters.

## Scope Excluded

Root public API removal; physical core split; global mutable registries; arbitrary async network
I/O; editor plugins/CLI explain/diff (P3); broad property/mutation/performance gates (P2); framework
adapter rewrite not required by the compiled representation.

## Dependencies

P0 terminal. Within P1: IR/diagnostics contracts precede graph/pipeline; compatibility facade and
current behavior remain green throughout; plugin/subpath work follows compiler contracts rather
than defining them backwards from exports.
