### P1.1 — Characterize contracts and freeze IR ADRs

**Intent:** Freeze the observed authoring→runtime behavior and the identity/value/source/metadata invariants for the canonical IR before migration.

**Why:** The same semantics currently span core entrypoints and direct package consumers; implementation without characterization risks an accidental public rewrite.

**Scope Included:** Call/import graph; API and output snapshots; DSL/DTCG/runtime seam inventory; ADRs for identity, references, metadata, immutability and compatibility adapter.

**Scope Excluded:** Production IR implementation; public export change; package split.
