# P3 — Explainability, delivery tooling and durable documentation

## Phase Context

P3 exposes the compiler evidence built in P1/P2 to developers and non-TypeScript consumers. CLI
commands and Vite manifests consume one canonical compiled representation and diagnostic model;
they do not implement a second resolver. Permanent architecture/ADR/compatibility documents replace
the archived execution plan as the durable explanation of behavior.

> **Контракт фазы (contract-first).** Потребляет: terminal P1 compiler/diagnostics and P2
> conformance fixtures. Производит: inspect/explain/graph/diff surfaces, typed Vite virtual module,
> deterministic manifest/CSP artifacts, selected lint/testing tooling and maintained architecture
> docs. Границы: no framework-specific compiler fork, no Composer resolver, no consumer-triggered
> adapter, no actual ecosystem pilot claim.

> **Phase Assurance | v1.**
> Impact: public-contract
> Integration Seams: cli-output · vite-manifest · csp-artifact · docs-contracts
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: Machine-readable outputs and migrations are public contracts; each item must carry
> schemas/snapshots and packed-consumer tests, while trigger-gated ecosystem additions remain out.

## DoR (Definition of Ready)

- [x] P2 items define the stable fixture and consumer evidence consumed by P3.
- [x] Every CLI/manifest output is required to have a versioned machine contract.
- [x] Testing/stylelint publication choices are evidence-gated and decision-backed.
- [x] Vite/Laravel artifacts are constrained to one compiler source and atomic writes.
- [x] Documentation ownership and drift checks are assigned to P3.6.

## Scope Included

CLI `inspect`, `explain`, `graph`, `diff` and selected `doctor/migrate` behavior; pretty/json/github
diagnostic formats; typed Vite virtual module; deterministic PHP-readable manifest and anti-FOUC
CSP hash artifact; atomic watch output; selected testing/stylelint package or internal tool based on
P2 evidence; architecture overview/package graph/compiler/token/diagnostic/runtime/security/
extension/compatibility docs and ADRs; documentation generated from compiler schemas where useful.

## Scope Excluded

PHP/Composer token resolver; Blade components; Laravel Mix; new UI/framework adapters; hidden
network access; IDE extension; automatic migrations without dry-run/diff; publication of a package
without its P2 evidence and decision.

## Dependencies

P2 terminal. Explain/graph precede diff/migrate. Vite manifest consumes frozen compiler/fingerprint.
Lint/testing publication follows P2 conformance reuse verdict. Docs consolidate only terminal
contracts and are checked against their machine owners.
