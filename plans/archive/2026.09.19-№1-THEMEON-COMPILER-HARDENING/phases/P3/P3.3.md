### P3.3 — Typed Vite module, manifest and CSP artifact

**Intent:** Emit one typed virtual module and deterministic PHP-readable manifest/CSP artifact from the canonical compiled result with atomic watch updates.

**Why:** Vite and Laravel consumers need build artifacts without implementing a second TypeScript token resolver or observing partial writes.

**Scope Included:** Versioned virtual-module types; manifest schema; integrity/fingerprint; anti-FOUC CSP hash artifact; atomic write/rename; HMR invalidation.

**Scope Excluded:** Composer/PHP resolver; Blade components; Laravel Mix; deployment configuration.

**Inputs:** `phases/P1/P1.5.state.md`; `phases/P2/P2.3.state.md`; `phases/P2/P2.5.state.md`; `packages/vite/src/index.ts`; `packages/vue/src/anti-fouc.ts`

**Files:** `packages/vite/src/**`; `packages/vue/src/anti-fouc.ts`; approved core manifest types; Laravel/Vite consumer fixtures and docs.

**Required Reads:** `plan.md`; `phases/P3/P3.md`; `phases/P1/P1.closed.md`; `phases/P2/P2.3.md`; `phases/P2/P2.5.md`; `packages/vite/src/index.ts`; `packages/vite/src/index.test.ts`; `packages/vue/src/anti-fouc.ts`; `packages/vue/src/anti-fouc.test.ts`; `tests/integration/package.json`

**Implementation Rules:** One compile per invalidation; consumers read artifacts only; stable schema/version; atomic same-filesystem replacement; CSP hash derives from exact emitted bytes.

**Code Guidance:** Keep filesystem adapter outside compiler; debounce without losing final update; clean stale artifact only when ownership marker matches.

**Validation:** Typed virtual import; manifest schema/golden; PHP-readable packed fixture; interrupted-write test; HMR freshness; CSP determinism; root checks.

**Deliverables:** Virtual module, manifest/CSP artifacts, atomic watcher behavior, schemas and consumer proof.
