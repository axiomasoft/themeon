### P2.6 — Browser and adapter conformance; testing-kit verdict

**Intent:** Prove browser/runtime/adapters consume the same compiled contract and decide whether shared testing utilities remain internal or merit a package.

**Why:** Adapter drift and browser-only failures are integration risks; a testing package is justified only by observed independent reuse.

**Scope Included:** Chromium PR smoke; periodic Firefox/WebKit; Tailwind/Vue/Nuxt/Naive consumed/ignored/diagnostic cases; anti-FOUC; reuse count and package disposition decision.

**Scope Excluded:** New adapter semantics; unsupported browsers; automatic `@themeon/testing` publication.

**Inputs:** `phases/P1/P1.4.state.md`; `phases/P1/P1.5.state.md`; `phases/P2/P2.1.state.md`; `phases/P2/P2.3.state.md`; `phases/P2/P2.5.md`; `phases/P2/P2.5.state.md`; `decisions/D4-consumer-gated-ecosystem.md`

**Files:** Adapter/browser tests; Playwright-equivalent config if selected; CI workflows; internal test helpers; decision file.

**Required Reads:** `plan.md`; `phases/P2/P2.md`; `phases/P2/P2.3.md`; `phases/P2/P2.5.md`; `packages/vue/src/index.ts`; `packages/vue/src/anti-fouc.ts`; `packages/nuxt/src/module.ts`; `packages/tailwind/src/index.ts`; `packages/naive/src/index.ts`; `decisions/D4-consumer-gated-ecosystem.md`

**Implementation Rules:** One conformance vocabulary; adapters cannot re-resolve; publication requires at least two real internal reuse sites plus an independent public contract.

**Code Guidance:** Prefer behavior assertions over framework internals; keep browser state isolated; collect traces only on failure.

**Validation:** Cross-adapter matrix; Chromium PR and Firefox/WebKit periodic smoke; anti-FOUC parity; decision evidence; affected/root checks green.

**Deliverables:** Conformance suite, browser lanes, reusable fixture layer and accepted internal-vs-package decision.
