### P2.3 — Packed external-consumer matrix

**Intent:** Verify published tarballs in clean external consumers across supported module, build, SSR and DOM-free scenarios.

**Why:** Workspace tests can hide export, declaration, peer and bundler failures that real consumers encounter.

**Scope Included:** Pack/install matrix for TS ESM, Node DOM-free, Vite/Vue, Nuxt SSR, Laravel Vite, Tailwind and representative module resolution; clean cache controls.

**Scope Excluded:** Actual npm publish; unsupported frameworks; networked application deployment.

**Inputs:** `phases/P1/P1.closed.md`; `phases/P1/P1.6.state.md`; `phases/P0/P0.4.state.md`; `phases/P0/P0.5.state.md`; `packages/core/package.json`; `package.json`

**Files:** `tests/consumers/**`; pack scripts; integration workflow; minimal fixture lockfiles/manifests.

**Required Reads:** `plan.md`; `phases/P2/P2.md`; `phases/P1/P1.closed.md`; `phases/P0/P0.md`; `package.json`; `pnpm-workspace.yaml`; `packages/core/package.json`; `packages/vite/package.json`; `packages/vue/package.json`; `tests/integration/package.json`

**Implementation Rules:** Install generated tarballs, never workspace links; pin toolchain; each fixture asserts public behavior and absence of forbidden DOM/server coupling.

**Code Guidance:** Share harness, not consumer config; isolate temp dirs; report package digest and resolver mode on failure.

**Validation:** Every matrix cell packs/installs/typechecks/builds/imports; SSR and DOM-free smoke execute; forced broken export proves gate; root checks green.

**Deliverables:** Reproducible consumer matrix, CI lane, fixture inventory and failure diagnostics.
