### P1.2 — Canonical immutable IR and input normalizers

**Intent:** Add one DOM/framework-free immutable IR and normalize current DSL and DTCG inputs into it while preserving public behavior.

**Why:** Resolver, emitters and adapters need one loss-aware representation rather than format-specific parallel models.

**Scope Included:** IR types/builders; source and metadata carriage; DSL/DTCG normalizers; read-only invariants; compatibility facade back to current call shapes.

**Scope Excluded:** Reference graph; transforms/emitters; root API removal; new npm package.

**Inputs:** `phases/P1/P1.1.md`; `phases/P1/P1.1.state.md`; `phases/P0/P0.1.state.md`; `decisions/D1-compatibility-first-compiler.md`; `decisions/D2-dtcg-loss-policy.md`

**Files:** `packages/core/src/{authoring,model}/**`; compatibility files under `packages/core/src/*.ts`; focused IR/normalizer tests.

**Required Reads:** `plan.md`; `phases/P1/P1.md`; `phases/P1/P1.1.md`; `phases/P1/P1.1.state.md`; `phases/P0/P0.1.md`; `phases/P0/P0.1.state.md`; `packages/core/src/types.ts`; `packages/core/src/define.ts`; `packages/core/src/dtcg/from-dtcg.ts`; `packages/core/src/dtcg/to-dtcg.ts`; `packages/core/src/dtcg/from-dtcg.test.ts`; `packages/core/src/dtcg/to-dtcg.test.ts`

**Implementation Rules:** Normalize without silent data loss; retain stable identity and source provenance; expose no mutable registry; keep core at zero runtime dependencies.

**Code Guidance:** Use discriminated typed nodes and readonly collections; isolate legacy adapters; reject impossible states at the normalization boundary.

**Validation:** Core tests/typecheck/build; DSL and DTCG fixtures normalize deterministically; legacy fixtures remain byte/semantic compatible; dependency scan proves no DOM/framework import.

**Deliverables:** Canonical IR, two normalizers, legacy compatibility facade and invariant tests.
