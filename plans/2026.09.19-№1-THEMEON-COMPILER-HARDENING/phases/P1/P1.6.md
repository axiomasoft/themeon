### P1.6 — Additive subpaths and compatibility migration

**Intent:** Publish additive `authoring/compiler/runtime/dtcg/tenant` subpaths and migrate internals/consumers without breaking root imports.

**Why:** The compiler seams need stable entrypoints, but package splitting or root removal before consumer proof would create needless migration risk.

**Scope Included:** Internal directory placement; export map/types/build config; consumer imports where beneficial; API snapshots; compatibility guide.

**Scope Excluded:** Root removal; package split; major release; new public semantics.

**Inputs:** `phases/P1/P1.1.state.md`; `phases/P1/P1.2.state.md`; `phases/P1/P1.3.state.md`; `phases/P1/P1.4.state.md`; `phases/P1/P1.5.md`; `phases/P1/P1.5.state.md`; `decisions/D1-compatibility-first-compiler.md`; `packages/core/package.json`
