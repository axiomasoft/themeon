# @themeon/core

Typed design-token engine: author tokens in TypeScript, resolve them once, and emit the
**exact same** variable set through two channels — static CSS for the build (anti-FOUC in
`<head>`) and an inline runtime applier for theme/tenant switching without a rebuild. One
naming engine drives both, so build and runtime output are identical by construction. The
package also bridges to the [DTCG](https://www.designtokens.org/) interchange format.

**Zero runtime dependencies** (L0).

> **Status: pre-1.0 — the API may change.** Pinned by a public-surface snapshot test, but not
> yet stable.

## Install

```sh
pnpm add @themeon/core
```

ESM-only, Node `>= 22.18`.

## Quickstart

```ts
import { defineTokens, defineTheme, resolveTheme, serializeThemeCss, applyTheme, themeVars } from '@themeon/core'

// 1. Author tokens. A leaf that is another Token is a reference.
const palette = defineTokens('color', {
  forest: { 600: 'oklch(0.55 0.13 155)' },
  neutral: { 0: 'oklch(0.99 0 0)', 900: 'oklch(0.15 0 0)' },
})

// 2. Define a theme: a base contract plus named partial patches.
const theme = defineTheme({
  base: {
    color: {
      bg: { page: palette.neutral[0] },
      action: { primary: palette.forest[600] },
    },
    space: { 4: '1rem' },
    text: { '2xl': { size: '1.5rem', lineHeight: 1.33 } },
  },
  themes: {
    dark: { color: { bg: { page: palette.neutral[900] } } },
  },
})

// 3. Resolve once — collapses reference chains, applies the naming engine, detects cycles/collisions.
const resolved = resolveTheme(theme, { refLayer: 'referenced' })

// 4a. Build channel — static CSS for <head>.
const css = serializeThemeCss(resolved)
// @layer themeon.tokens { :root { color-scheme: light; --color-neutral-0: oklch(0.99 0 0); --color-bg-page: var(--color-neutral-0); … } … }

// 4b. Runtime channel — inline variables, same names & values as the CSS.
applyTheme(document.documentElement, themeVars(resolved))
applyTheme(document.documentElement, themeVars(resolved, 'dark')) // switch theme
```

## `resolveTheme(def, options)`

| Option | Type | Default | Meaning |
|:--|:--|:--|:--|
| `prefix` | `string` | `''` | Prefix after `--`: `'to'` → `--to-color-primary`. |
| `aliases` | `'legacy-v0' \| (path) => name \| null` | — | Emit legacy alias variables alongside canonical ones. |
| `refLayer` | `'referenced' \| 'all' \| 'inline'` | `'referenced'` | Reference-layer transport: emit only directly-referenced palette vars as a `var()` chain (`referenced`), all reachable ones (`all`), or inline final values (`inline`). |

`ResolvedTheme` carries `tokens` (base), `themes` (patches), `aliases`, `breakpoints`,
`schemes`, and a flat `vars` dictionary — the single source both the serializer and the
applier consume verbatim.

## `serializeThemeCss(resolved, options)`

| Option | Type | Default | Meaning |
|:--|:--|:--|:--|
| `layer` | `string \| false` | `'themeon.tokens'` | Cascade-layer wrapper; `false` disables it. |
| `selector` | `string` | `':root'` | Base block selector. |
| `themeAttribute` | `string` | `'data-theme'` | Attribute for theme blocks (`[data-theme="dark"]`). |
| `emitCustomMedia` | `boolean` | `true` | Emit `@custom-media --bp-<name>` for breakpoints. |
| `customMediaPrefix` | `string` | `'bp-'` | Prefix for custom-media names. |
| `emitColorScheme` | `boolean` | `true` | Emit `color-scheme` in `:root` and theme blocks. |
| `emitProperty` | `'none' \| 'color'` | `'none'` | Register base color tokens via top-level `@property`. |
| `banner` | `string \| false` | `/* generated by @themeon/core */` | Leading comment. |

> **`@custom-media` is not Baseline.** It is not shipped natively by browsers — consumers need
> [postcss-custom-media](https://github.com/csstools/postcss-plugins) or LightningCSS to compile
> it. Set `emitCustomMedia: false` to skip it.

## Runtime applier

- `themeVars(resolved, theme?)` — the variable dictionary to apply (base, or a named theme's patch).
- `applyTheme(el, vars)` — writes variables inline via `setProperty` (dev-time validation warns on invalid pairs).
- `clearTheme(el, names | resolved)` — removes variables (`removeProperty`, the canonical reset).

## DTCG interchange

`toDTCG(def)` exports a multi-file DTCG 2025.10 bundle (`base.tokens.json`,
`<theme>.tokens.json`, `themeon.resolver.json`) that Terrazzo / Style Dictionary consume
directly; `fromDTCG(files)` imports one back into a `ThemeDefinition`. See the
[DTCG format spec](https://www.designtokens.org/TR/2025.10/format/).
